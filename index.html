Конструктор промптов для интерактивных HTML-игр

Соберите промпт для нейросети за несколько шагов

Выберите игровую механику, задайте параметры урока, добавьте подходящую обратную связь и вовлечение. В конце появится готовый промпт, который можно вставить в любую нейросеть для создания HTML-игры.

1

Выберите основную механику

В конструкторе заложены 32 основные механики. Комбинированная игра из нескольких этапов сюда не добавлена.

2

Заполните основу игры

Предмет, класс, тема и параметры выбранной механики.

3

Настройте визуальный стиль

Этот блок заставляет нейросеть менять не только цвет кнопок, а всю визуальную систему игры: фон, карточки, декор, палитру и атмосферу.

4

Выберите обратную связь

Показываются только блоки, которые подходят к выбранной механике. Можно ничего не выбирать.

5

Выберите вовлечение

Эти блоки усиливают игру, но не обязательны. Можно оставить промпт без механик вовлечения.

6

Дополнительные условия

Напишите всё, что важно: без внешних картинок, крупный шрифт, мобильная версия, свои задания, ссылки на изображения, ограничения по стилю.

7

Готовый промпт

Нажмите кнопку, затем скопируйте текст и вставьте в нейросеть.
