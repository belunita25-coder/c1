Конструктор сложной HTML-игры

Соберите промпт для игры из нескольких этапов

Задайте число этапов, выберите механику для каждого, настройте их по отдельности. Общие правила игры — баллы, награды, сюжет, финал — задаются один раз для всей игры. В любом списке можно выбрать готовый вариант или вписать свой.

1

Основа игры

Количество этапов, предмет, класс, тема и формат результата.

💡 В каждом выпадающем списке последний пункт — «✍️ Свой вариант». Выберите его, и появится поле, куда можно вписать что угодно своими словами. В текстовых полях примеры выпадают при нажатии.
2

Набор механик по этапам

Порядок выбора становится порядком этапов. Одну механику можно поставить на несколько этапов — например, короткая викторина в начале и она же в конце.

Выбрано 0 из 3

3

Настройки каждого этапа

Параметры механики и реакция на ответы — отдельно для каждого этапа. Настройки сохраняются при перестановке и добавлении этапов.

4

Правила для всей игры

Баллы, жизни, награды, сюжет, персонаж, финальный экран. Задаются один раз и действуют на всех этапах — поэтому их нет в настройках отдельных этапов.

5

Стиль и оформление

У каждого стиля из списка есть готовый рецепт оформления — палитра, фон, карточки, декор и шрифт. Он попадёт в промпт, чтобы нейросеть оформила игру целиком, а не только перекрасила кнопки.

Цвета этого конструктора нужны только интерфейсу выбора. У самой игры должна быть своя палитра под выбранный стиль.
6

Дополнительные условия

Ограничения, свои задания, требования к адаптации и размещению на сайте.

7

Готовый промпт

Промпт обновляется сам при каждом изменении. Если очистили поле — нажмите «Создать промпт», чтобы собрать заново.
